## 📸 Scanner De Comprovantes Com IA

<img src="https://github.com/felipelunelli-dev/Scanner-De-Comprovantes-Com-IA/blob/main/Scanner%20Preview.png">

Aplicação desenvolvida para simplificar o registro de despesas através da leitura de comprovantes.

O usuário envia ou fotografa um comprovante e a aplicação utiliza **Inteligência Artificial** para interpretar as informações e registrar o gasto automaticamente.

## 🚀 Funcionalidades

* 📷 Upload de comprovantes
* 🤖 Leitura e interpretação utilizando IA
* 💰 Identificação automática de valores
* 🧾 Registro de despesas
* 📊 Exibição do total gasto
* 🔄 Atualização automática das informações
* 📱 Interface simples e responsiva

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* API / Inteligência Artificial

## 💡 Objetivo do projeto

O projeto nasceu da ideia de tornar o controle de gastos mais rápido e simples.

Em vez de registrar cada compra manualmente, o usuário pode enviar uma foto do comprovante e deixar que a aplicação interprete as informações.

Além de praticar desenvolvimento Front-End, o projeto também explora a integração de aplicações web com **Inteligência Artificial**.
